本目录包含两套模型专版技能：

- DeepSeek 专版
- Qwen 专版

安装方法：

1. 选择你要用的那一套，或两套都装
2. 将对应 skill 目录直接解压或复制到：
   - %USERPROFILE%\.codex\skills\
   - 或 %CODEX_HOME%\skills\
3. 不要多套一层父目录

建议：

- DeepSeek-R1 / 更短上下文：优先装 `agent-workbench-deepseek-*`
- Qwen 32K / 稍宽上下文：优先装 `agent-workbench-qwen-*`

这两套技能都围绕以下目标做了专门压缩：

- 减少模型自己组织长命令链
- 减少 PowerShell 语法误用
- 优先单命令 `verify current`
- 输出格式固定
- evidence-first，减少幻觉
