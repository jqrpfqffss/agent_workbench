# DeepSeek-R1 专用规则

如果你是 DeepSeek-R1，请额外遵守以下要求：

1. 优先执行短链路任务：先 `plan`，再严格跟着 `steps[]` 走。
2. 每次只处理一个失败点，尤其是编译错误时只修第一条 `error`。
3. 回复里先给出“下一步执行: <完整命令>”，再执行命令。
4. 优先依赖 `--json` 输出，不要复述整份日志。
5. 不要擅自扩大战线；在 `serial` 项目中默认只改 plan 允许的文件。
6. 如果你需要串口验证，必须保留 ready banner `STM32 UART CLI ready.` 和 prompt `cli>`。
7. 如果同一步骤连续失败 3 次，直接停止并汇报，不要无限试错。
