# CLI 调试分类说明

## 1. rx_zero

含义：

- 板子没有收到任何有效 UART 字节

常见原因：

- 选错串口
- 接线错误
- 实际 UART 口与配置不一致
- 主机命令没有真正发出去

## 2. parser_no_command

含义：

- 已收到字节，但没有形成有效命令或没有进入命令分发

常见原因：

- 行结束符处理异常
- 输入缓存问题
- 命令解析器逻辑异常

## 3. tx_or_host_rx

含义：

- 命令可能已经执行，但主机没有正确拿到输出

常见原因：

- 输出发送链路异常
- 主机侧读取时序问题
- 串口工具或抓取方式不对

## 4. ready_missing

含义：

- 没看到配置中的启动 banner

重点排查：

- reset 时机
- 打开串口与复位的先后顺序
- banner 是否真的发送

## 5. prompt_missing

含义：

- 没看到 CLI 提示符

重点排查：

- 提示符是否不带换行
- host 侧是否按行读取导致漏掉 prompt

## 6. diag_unavailable

含义：

- 诊断符号不可读，不能把缺失诊断误判成 CLI 本身坏了

## 7. environment_blocked

含义：

- 当前无法证明是代码问题，因为环境本身不通
